# bilibili-electron

[GitHub 仓库](https://github.com/AntarcticBearHKL/O11A1) · [Releases](https://github.com/AntarcticBearHKL/O11A1/releases)

O11A1 的 Electron 桌面版：**主窗口 UI 由 Electron 绘制，视频播放窗口使用原生 Rust 覆盖层。**

当前状态：可运行的桌面客户端，界面 2.0 采用暖纸底色 + 全宽内容区 + 顶部头像/搜索/窗口钮 + 底部磨砂浮动工具栏，包含主窗口全部页面、原生 Rust 播放器窗口、原生弹幕、养鱼、账号设置与打包脚本。

## 架构

```text
Electron main (Node)
  ├─ BrowserWindow × 1   主窗口（HTML/CSS/React）
  ├─ tray / autostart / update check
  └─ local TCP JSON-RPC
        │
        └─ o11a1-engine.exe (Rust)
             ├─ core        Bilibili API / session / settings / downloads / fish
             ├─ native_player  FFmpeg + D3D11 + DComp + WASAPI + 插帧 + 增强
             └─ 原生播放器窗口（626×86 悬浮工具条、360px 五 tab 侧栏）
```

- 视频帧**不经过 Electron**：Rust 自己解码、处理并 Present 到原生窗口。
- 点击卡片后原生窗口先隐藏创建，等首页背景加载卡（旋转圆环 + 正在加载视频）和工具条绘制完成再一次性显示，不再先闪一个空框；播放源在后台解析，第一帧准备好后自动换上视频。关闭窗口时先立即隐藏，再做解码器 / 音频 / 状态保存等清理，不会卡一下。
- 视频卡左下角 UP 名加粗显示（正文色、600 字重）；点击任意页面的 UP 名进入其主页（推荐 / 搜索 / 分区 / 排行 / 收藏 / 历史 / UP 投稿全部生效），主页左上角「返回」回到上一页。
- 播放窗口无固定顶栏；底部 626×86 悬浮工具条使用首页同款暖纸面板（暖纸底 + 径向光晕 + 点阵，12px 圆角裁剪，1px 发丝边，完全不透明）；循环按钮与其它控件同为实底 chip，点击展开 `循环 / 继续 / 暂停` 三档菜单，循环档和菜单打开时让图标转蓝（没有描边、外圈光晕和底部横线），所有按钮悬停显示名称/状态 label，音量悬停弹出无文字 24×108 胶囊，点击/拖动只认胶囊本体，圆角上方空白不会改音量（整个工具条上方 10px，不重合，颜色从底部整段填充），加载提示卡使用首页暖纸 + 光晕 + 点阵并在视频画面区居中，暂停时不再弹出居中提示卡而是给整个窗口加一圈 4px 蓝色描边（内侧发丝线，无内侧光晕带，描边外缘与窗口 12px 圆角同心贴合，全屏方角），弹幕设置 / 增强菜单 / 插帧菜单打开时，左键或右键点击画面只会关闭菜单，不会暂停；弹幕设置 / 增强菜单使用半透明玻璃底（88% 弹窗；弹幕设置固定 7 行 40px 行距，首行是左「弹幕」标签 + 右侧空心胶囊开关（整行可点，只变边框颜色，无填充，关灰开蓝；分布密度同一开关），开关与下方数值右缘对齐、行宽一致，标签与按钮文字统一垂直居中，没有发送框和关闭 X），视频右上角是一枚暖纸关闭按钮（36×36、发丝边，悬停珊瑚红；没有最小化 / 最大化），按钮下方常驻暖纸 Debug FPS（两行：`画面 FPS 59.9 · 16.7 ms` 与 `弹幕 FPS x`，与面板同一 Chill Round Gothic 圆体；弹幕值按最近 1 秒实际绘制帧计数，无可见弹幕为 0），播放窗口和任务栏按钮使用 O11A1 图标（`o11a1.ico`，`native_player.exe` / `o11a1-engine.exe` 均内嵌）；右侧 360px 全高侧栏车道（窗口化向右扩展、全屏向内让位，铺首页暖纸 + 光晕 + 点阵背景，与视频补边共用同一套背景采样、没有接缝；顶部 tab 用首页底栏同款的滑动墨色胶囊做选中态，选中与未选中项使用同一 Chill Round Gothic 字族与行高居中，各分区头/列表行也按行框垂直居中，点击画面不会关闭，右键侧栏任意位置、当前 tab、同一工具条按钮或 Esc 关闭，拖动空白处可移动窗口），布局、按钮顺序和图标与 Rust 播放器一致。悬停格填充实色圆角块：最小化 / 最大化变蓝、关闭变珊瑚红，图标同时转白。右键进度条时工具条会向上展开为精准定位面板（再次右键或 Esc 收回，卡片高度与内容 360ms 同步过渡）：最左播放/暂停、随后 200×30 时间胶囊、右侧 200×30 帧号胶囊（同一 12.5px 半粗字体与颜色）、满宽弹幕热力图、A/B 主宽度 + 至少 72px 淡红清空、满宽移动式帧数标尺轮（蓝色主齿带顶部刻度帽与相对帧数标签）与 92px 帧步下拉；滚轮只移动预览、停止约 280ms 后一次性定位，拖动松手后才跳转；A/B 循环提前预热 A 起点、不重新加载解码器；向左拖动 / 向下滚轮为前进；顶行和各行统一 20px 内边距；面板内嵌与工具条完全一致的播放/暂停按钮。评论边栏使用 14px 正文、可展开楼中楼，头部与排序随列表滚动。
- 视频锁定源比例，直接铺在窗口里：窗口与视频比例不一致时只在一个方向补边，另一方向贴住窗口边缘，不会四周加画框，也不会透出桌面；视频四角保留 12px 小圆角，补边也铺首页暖纸 + 光晕 + 点阵，不再使用单独的纯色板。主窗口和播放器窗口都有外阴影：主窗口用 yah 同款 22px 透明留边 + 18px 圆角 + 三层阴影，播放器用独立的 26px 穿透阴影窗口，窗口不再和后面的窗口融为一体。侧栏以全高车道贴在画面右边：窗口化时窗口向右扩展、画面尺寸不变，全屏时向内让位；车道高度与视频窗口一致，没有底部窗口包裹；右键画面或侧栏任意位置都能关闭。
- 左侧边栏已删除，内容区占满整个窗口。顶部栏是一层覆盖在内容上的透明磨砂条：左侧是用户头像（点击展开账户菜单），中间是 320px 搜索框（默认显示浅灰 `搜索视频或 UP 主` placeholder，没有快捷键提示；展开后铺满头像与窗口钮之间的全部宽度并在输入框内保留 placeholder；打开时右键任意位置关闭，不触发页面长按刷新），右侧是最小化 / 最大化 / 关闭；页面滚动时会从顶栏下方经过，磨砂实时生效。
- 底部新增居中磨砂浮动工具栏：左侧「推荐 / 收藏 / 分区 / 番剧 / 直播」，中间是放大的 84px 单独黑胶光盘（有播放时旋转，无播放时中间为空，不再显示数字角标；点击展开播放队列；队列浮层只保留标题、列表和有内容时的「清空」，视频结束默认自动下一条并移除已播项，末条播完移除后关闭播放器，手动关闭播放器也移除当前项），右侧「养鱼 / 动态 / 消息 / 历史 / 刷新」。刷新按钮常驻蓝色圆形背景；切换 tab 时一枚共享深色圆片在工具栏上滑动，所有工具图标按实际笔画居中。下载入口暂时完全隐藏，账户与设置从左上角头像菜单进入。
- 插帧按钮点击展开关闭 / 60 / 90 / 120 / 自动五档菜单，自动跟随显示器刷新率；固定挡位高于屏幕刷新率时灰显不可选；键盘 I 在可用挡位间循环。插帧带一帧 lookahead 和切镜保护，不自动关闭，不补帧、不冻结；双击画面切换全屏，空格播放/暂停；单击会先等系统双击间隔，确认不是双击后才暂停/继续，双击不会先闪一下暂停，已生效的单击也不会和下一击拼成双击。
- 界面禁用框选与原生右键菜单；非互动区域左键拖动窗口，右键长按 0.4 秒刷新（视频卡、悬停按钮、tabs 和工具条都可以，输入框 / 文本域除外），光标处显示一圈 44px 极简进度环（3px 轨道 + 3.8px 蓝色弧从 12 点顺时针填充，无图标 / 文字 / 卡片 / 光晕），16px 内跟随鼠标；卡片和按钮不再阻止刷新，也不会留下焦点边框。播放器弹幕右键菜单支持按住右键拖到选项后松开直接生效。主窗口/播放器外沿使用 12px 小圆角，播放队列改为底部工具栏中央的旋转黑胶，点击向上展开。
- 全应用（主界面、登录页、原生播放器、弹幕）统一使用本地打包的 **Chill Round Gothic（寒蝉圆黑体）** 400/500/700；它基于思源黑体 SC 做圆角化，覆盖常用简体与「巽」等少见字，不再需要 Chiron 回退；所有滚动区域隐藏滚动条，滚轮和触控滚动照常。
- 启动时已保存账号先校验登录态，仍有效才自动进主页；会话失效（-101）时保留头像并回到扫码登录；无账号显示单一最小登录卡：首页暖纸 + 光晕 + 点阵上居中 392px 小卡，只有圆形用户头像（优先上次登录账号的真实头像，退出登录也会保留）、直接嵌在表面的二维码（无独立白卡 / 边框 / 阴影 / hover 抬起，浅色主题静区与表面同色）、二维码生成中显示同一位置的模糊二维码幽灵（没有额外小进度条）、一条 6px 加载条和一行状态文字（22px 行距、状态行高 1.75）；没有品牌、标题、说明或按钮。应用内账户页退出后的扫码页复用同一张卡，启动页和扫码页不再有两套设计。
- 启动/登录期间在后台预载每个页面的默认首屏：收藏、历史、分区、番剧、直播、动态、消息、账户、养鱼，加上搜索热词与历史；首次打开页面直接显示内容，不再先闪骨架屏。数据放在一次性内存缓存里，退出登录时清空。
- Debug 模式默认开启：右上角实时显示 `FPS 120.0 · 8.3 ms`；F12 / Ctrl+Shift+H 或头像菜单切换，并记住选择。
- 首页推荐流固定显示 **7 行**，加载时按屏幕宽度计算列数与请求数量（一次请求 7×列数 张卡片）；滚到底不再追加下一页；点底部刷新或右键长按刷新会先回到顶部，再换入一批后台预载好的推荐，随后继续静默补齐两批缓存。所有视频封面走容错链（480px 缩略图 → 原图 → 重试 → 占位卡），空 URL / CDN 404 / 网络失败都不会留下空框。滚动优化保留：480px CDN 缩略图、顶栏与底栏全程实时 backdrop blur、只让前 14 张卡片做入场动画、图片异步解码。120Hz 下滚动实测约 119 FPS。
- 视频卡不再使用系统原生 title：整卡悬停没有全名提示，只有标题上出现暖纸扁平浮层（最大 400px、发丝边、无左侧竖线，靠边自动夹取、顶部放不下就翻到下方）；发布时间胶囊悬停显示具体日期时间、播放量和相对时间，UP 名悬停不再显示提示框。
- 整窗左键拖动和四边/四角缩放采用非模态实现：拖动/缩放期间视频继续播放，松手不会误触暂停。
- 关闭原生窗口会自动释放播放器额度，连续打开/关闭三个窗口后仍能继续打开。
- 原生弹幕、评论、性能、画质/音轨/速度/亮度/插帧/增强/设置都在原生播放器覆盖层内。评论按最热 / 最新排序，接近底部自动连续加载；正文用 14px Chill Round Gothic，楼中楼展开后缩进显示、无灰底气泡，收起后不保留预览；评论头部与排序随列表一起滚动。
- 番剧集和普通视频共用同一条播放管线：季详情里的 `bvid` / `cid` / `aid` 直接启动原生播放器，画质菜单列出全部 DASH 分辨率与编码并可切换，弹幕按集 cid 拉取显示；只有缺少 bvid 的旧数据才回退到 PGC 直链。
- 弹幕由 Rust 按视频时钟调度并绘制在视频层上；Electron 只负责开关、参数、发送、历史列表与点赞/举报/屏蔽操作。
- 精准定位面板的帧数标尺可以像时间轴一样连续拖动：拖动时标尺跟着手指走、只预览目标时间，松开鼠标才 seek 一次；不足一格的轻微抖动不会跳帧，也不会每走一格就回弹归零。标尺没有拖动上限，鼠标能拖多远刻度就延伸多远；视频目标位置仍夹在总时长内。
- 精准定位面板的 A/B 行右侧始终显示淡红「清空」按钮；已修复 release 构建下 D2D 画笔颜色取临时引用导致按钮整颗不可见的问题。
- A/B 循环从进入区间起就预热下一次 A 起点；≤2 秒的 A–B 会在第一遍播放时缓存解码帧，之后直接从内存回放，不再每次 seek 重开视频解码器；更长区间由预取 decoder 在 B 无缝换入。

详见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 运行

需要 Node.js 24+、Rust stable（MSVC）、FFmpeg。开发数据目录是 `%APPDATA%\o11a1-electron\data`，首次启动会尝试从旧安装版复制设置/账号/历史。

```powershell
npm install
# 第一次安装后，若 Electron 二进制没有下载：
node node_modules/electron/install.js
node node_modules/esbuild/install.js

npm run build:renderer
# 构建 Rust sidecar（默认复用 D:\Dev\bilibili-slint\target）
powershell -ExecutionPolicy Bypass -File scripts/build-engine.ps1
npm start
```

开发时可以用 `npm run dev`（Vite + Electron）。

## 打包

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package.ps1
```

脚本会构建 Rust engine、复制字体/FFmpeg 到 `runtime/`、构建 renderer，并调用 `electron-builder` 生成 NSIS 安装包到 `release/`。

| `STATUS.md` | 已实现/已知差异/验证记录 |
| `ARCHITECTURE.md` | 进程、窗口、IPC、视频、弹幕设计 |
